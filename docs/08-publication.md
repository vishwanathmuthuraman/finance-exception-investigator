## Release package

The intended v1 package contains implementation, dependency lockfile, schemas, development fixtures, frozen benchmark manifests, evaluator code, results, failure analysis, six-minute demo and completed release checklist. After scoring is frozen, publish held-out inputs and oracles for reproducibility if their license permits; acknowledge that they become public test material for later users.

Use a concise case study: problem, narrow scope, deterministic baseline, optional AI contribution, actual comparison, failure example and what remains unknown. Evidence links should support every numerical claim. Avoid “production-ready,” savings, accuracy or compliance claims without matching evidence.
